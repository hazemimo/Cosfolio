# Cosfolio · 偶像写真工房 0.9

本版采用更深的海未蓝白配色，加入双图对比选片、模板搜索与收藏、透明 PNG 批量导出、编号联系表，以及模板自定义重命名。完全离线，没有新增模型。

## 开始使用

完整解压 Windows 发行包，保留整个文件夹，双击 Cosfolio.exe。无需安装 Python，无需联网处理照片。

旧 .cosfolio 工程可以直接通过“工程图库 → 打开工程文件…”打开。已有精修照片可在照片库“收录当前工程照片”，无需再次抠图。

已有 0.8 照片库时，可以在 0.8 导出 .cosphotos 归档包，再到 0.9 的照片库“恢复归档包”。也可以在关闭两个版本后，将旧版 workspace/library 文件夹复制到新版 workspace/ 中；应完整复制 library.sqlite3 和 files/。不要只复制数据库。

## 双图对比选片

在照片库中按住 Ctrl 选择两张照片，点击“**双图对比选片**”。

- 滚轮缩放，直接拖动照片平移；默认同步两张照片的倍率与画面中的相对位置。
- “适合窗口”显示整张照片，“100% 原始像素”按原始图片的像素显示，方便比较表情、对焦和细节。低倍使用快速预览，高倍在后台读取当前区域的原始像素，不把缩略图简单放大作为最终细节。
- 取消“同步缩放与移动”可以分别观察。重新勾选会以左图为基准同步。
- “查看原照片”切换原片和当前抠图蒙版的预览。原图本身不修改。
- 可分别收藏 A/B，Ctrl+Z 撤销收藏。“选中 A/B”返回照片库并选中对应照片。
- 两张照片构图不同时，同步位置按画面比例对应，人物对齐仍由使用者判断，不含人脸自动定位。

## 模板搜索、收藏和重命名

在版式页打开模板图库。顶部可按**模板名称、原名、说明**搜索，并按照片位置数量筛选，或勾选“只看收藏”。

选中模板后，右侧可以“收藏”“重命名”或“恢复模板原名”。自定义名称重新打开软件仍然保留，主界面与批量导出的模板名也会更新。图库内 Ctrl+Z / Ctrl+Y 可以撤销、重做模板名和收藏修改。

重命名仅更改管理名称，模板编号、画框坐标、底图和场刊原文字保持原样，不影响旧工程。名称和收藏保存在 workspace/template-preferences.json；迁移资料时可一并携带。重名会提示换一个名称，方便区分。

批量模板导出时，“全选/清空”作用于当前筛选结果。筛选前勾选的其他模板仍保留，顶部会标出筛选外已勾选数量，避免遗漏。

## 按专辑批量导出透明 PNG

在照片库点击“**交付照片… → 批量导出透明 PNG…**”。选中照片时导出选择内容；没有选择时导出当前专辑或筛选结果。

可选择原图像素，或最长边不超过 3000/6000/8000。使用原图和当前保存的精修蒙版，透明背景保留；不带入各工程独立的调色、投影或排版，不额外放大小照片。

每次建立独立导出文件夹，以编号和照片名命名，避免重名覆盖。PNG 附带 sRGB 和 300 PPI 信息，实际尺寸会写入“导出清单.json”。300 PPI 是尺寸标记，不会增加原照片细节。

## 编号选片联系表

在同一“交付照片…”菜单选择“**生成编号选片联系表…**”。可设置标题、每页 3/4/5 列；每列布局对应每页最多 15/20/25 张，自动分页。输出为 2400 × 3300 PNG，包含编号、照片名和标签。

默认显示原照片，取消“使用原照片”则显示透明主体。顺序与当前照片网格一致，跨页连续编号；附带“选片编号.csv”保留完整照片名称，方便摄影与 coser 按编号讨论选片。

较长的照片名在图片中可能省略显示，完整名称可在 CSV 清单查询。联系表不改变原照片或照片库中的状态。

## 取消与资料保留

上述批量交付均在后台执行，可取消。取消后保留已完成的照片或完整联系表页面，未完成文件清除；详细结果可查看输出目录中的清单。不会自动删除照片库或旧版程序中的素材。

照片库继续支持专辑、拖动整理、标签、收藏、精修版本、归档和恢复。原图与最初抠图基准保留；从照片库加入工程会生成独立素材，后续精修不会改变已完成工程。

成品排版导出仍默认 6000 像素、最高 8000 像素。22 款原有模板、多页写真、原场刊参考、抠图精修与模板向导继续可用。首次打开不附带示例照片。
