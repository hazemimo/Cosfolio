# Cosfolio 0.9.0-beta.1 · 首次公开测试

Windows x64 本地写真排版工具，海未蓝白界面，应用代码公开、非商业授权。

## 普通用户下载

选择 **Cosfolio-v0.9.0-beta.1-Windows-x64.zip**。完整解压后双击 Cosfolio.exe，保留整个文件夹。已包含 Python 运行环境和本地 BiRefNet 模型，无需自行安装依赖，照片处理无需联网。

**Cosfolio-v0.9.0-beta.1-source.zip** 是应用源码和构建资源，不是可直接双击运行的软件。SHA256SUMS.txt 用于校验下载内容完整性。

## 功能

- 本地抠图与可撤销的蒙版精修，保留原片。
- 22 款模板、原场刊参考、本地导入场刊与新建模板向导。
- 自由选片、拖放构图、可编辑文字模式、多页工程。
- 照片库专辑、标签、收藏、蒙版版本、双图对比及素材复用。
- 默认 6000 / 最高 8000 像素导出，透明 PNG 批量交付和编号联系表。
